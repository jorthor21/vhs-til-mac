# libusb 1.0.27 (innebygd)

Uendret kopi av kildefilene som trengs for macOS fra
https://github.com/libusb/libusb (tag v1.0.27). Lisens: GNU LGPL 2.1 (se COPYING).

Kun `config.h` er skrevet for dette prosjektet. libusb kompileres statisk inn i
appen. Hele kildekoden til appen og byggeskriptet følger med, slik at du kan
bytte ut libusb og bygge appen på nytt (krav i LGPL 2.1 § 6).
